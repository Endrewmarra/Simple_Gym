# Glossário

| Termo | Significado no projeto |
|---|---|
| Academia | Academia Ginásio 18. |
| Aluno ou cliente | Pessoa matriculada que utiliza os serviços da academia. |
| Administrador | Usuário responsável por atividades de gestão da academia. |
| Anamnese | Levantamento de informações do aluno utilizado como apoio à elaboração do treino. |
| Avaliação antropométrica | Registro de medidas e dados corporais do aluno. |
| CREF | Registro profissional exigido dos treinadores externos, conforme a regra de negócio RN10. |
| ERS | Especificação de Requisitos do Sistema. |
| LGPD | Lei Geral de Proteção de Dados Pessoais, mencionada nas regras e requisitos do projeto. |
| Stakeholder | Pessoa ou grupo envolvido ou impactado pelo sistema. |
| User story | Forma de registrar uma necessidade pela perspectiva de um usuário. |
