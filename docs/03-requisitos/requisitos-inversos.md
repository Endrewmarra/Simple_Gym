# Requisitos Inversos

> A ausência de `RI04` já existe no documento original. A numeração foi preservada para não prejudicar o histórico.

## RI01

**Descrição:** O sistema não deve permitir o acesso aos treinos nem às outras funcionalidades do aplicativo quando o cliente estiver com status bloqueado.

- **Referências:** RN04

## RI02

**Descrição:** O sistema não deve cadastrar usuários com idade inferior a 14 anos.

- **Referências:** RN02

## RI03

**Descrição:** O sistema não deve liberar a catraca para alunos com status bloqueado.

- **Referências:** RN04

## RI05

**Descrição:** O sistema não deve sugerir exercícios prejudiciais aos alunos que apresentem particularidades em sua anamnese.

- **Referências:** RN07
