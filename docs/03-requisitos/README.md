# Catálogo de Regras e Requisitos

Esta pasta contém a fonte principal das regras e dos requisitos do Simple Gym, mantida em Markdown para facilitar a revisão e o histórico de alterações pelo Git.

## Fonte

Os itens foram transcritos e padronizados a partir do documento `projeto-academia .docx` existente no repositório original. Não foram acrescentadas novas regras ou novos requisitos.

Correções de ortografia e formatação não alteram o sentido dos itens. A numeração original foi preservada, inclusive a ausência de `RI04`.

## Por que os itens estão separados por seção

Cada regra ou requisito ocupa sua própria seção Markdown. Isso facilita:

- visualizar exatamente o que mudou em um commit;
- comentar um identificador específico em uma revisão;
- adicionar novos itens sem reorganizar tabelas grandes;
- evitar conflitos quando integrantes editam categorias diferentes.
