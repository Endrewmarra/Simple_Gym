# Requisitos de Interface Externa

## RIE01-U

**Descrição:** O sistema deve ter uma interface amigável e intuitiva.

- **Prioridade:** Importante
- **Referências:** —

## RIE02-H

**Descrição:** O sistema deve receber entradas da catraca.

- **Prioridade:** Essencial
- **Referências:** RN14

## RIE03-C

**Descrição:** O sistema deve enviar ao aluno, por meio do aplicativo, notificações de alteração no status da matrícula.

- **Prioridade:** Importante
- **Referências:** RN04

## RIE04-S

**Descrição:** O sistema deve enviar ao site o valor do contador de lotação sempre que alguém passar pela catraca.

- **Prioridade:** Desejável
- **Referências:** RN14

## RIE05-S

**Descrição:** O sistema deve se comunicar com sistemas de pagamento on-line.

- **Prioridade:** Essencial
- **Referências:** —

## RIE06-C

**Descrição:** O sistema deve notificar o aluno sobre alterações no calendário ou nos horários de funcionamento da academia.

- **Prioridade:** Desejável
- **Referências:** —

## RIE07-H

**Descrição:** O sistema deve disponibilizar leitura facial para viabilizar a entrada do cliente.

- **Prioridade:** Essencial
- **Referências:** RN14
