# Histórias de Usuário

> Os códigos foram adicionados apenas para identificar e versionar as histórias pelo Git. Nenhuma nova história foi criada.

## US01 — Administrador

> Como administrador, eu quero que o sistema permita o cadastro de pelo menos 5.000 clientes, para que não seja necessário recadastrar alunos após períodos de pausa nos treinos.

## US02 — Administrador

> Como administrador, eu quero que o sistema permita o lançamento de mensalidades no cadastro dos clientes, para ter controle sobre o acesso deles à academia.

## US03 — Administrador

> Como administrador, eu quero que o sistema permita o lançamento de produtos no cadastro dos clientes, para ter controle sobre as mercadorias vendidas para cada cliente.

## US04 — Administrador

> Como administrador, eu quero que o sistema permita o cadastramento de diferentes modalidades de exercícios, para oferecer variedade de atividades aos clientes.

## US05 — Administrador

> Como administrador, eu quero que o sistema tenha compatibilidade com dispositivos de reconhecimento facial, para facilitar o acesso e o bloqueio de clientes em caso de inadimplência.

## US06 — Administrador

> Como administrador, eu quero que o sistema permita o cadastramento de avaliações antropométricas, para atender aos clientes.

## US07 — Administrador

> Como administrador, eu quero que o sistema permita a exportação de uma ficha com os dados da avaliação do cliente em PDF, para facilitar o envio ao cliente.

## US08 — Administrador

> Como administrador, eu quero que o sistema permita o cadastramento de máquinas e exercícios, para utilizá-los posteriormente na elaboração de treinos.

## US09 — Administrador

> Como administrador, eu quero que o sistema tenha a opção de cadastrar uma anamnese do cliente, para utilizá-la na elaboração dos treinos.

## US10 — Administrador

> Como administrador, eu quero que o sistema permita o cadastramento de treinos individuais para cada cliente, para agilizar os processos da academia.

## US11 — Administrador

> Como administrador, eu quero que o sistema permita a impressão e a exportação do treino para o cliente por meio de arquivo PDF, aplicativo ou mensagem via WhatsApp, para facilitar o acesso do cliente ao treino.

## US12 — Administrador

> Como administrador, eu quero que o sistema possua modelos predefinidos de treino feitos a partir da anamnese, para agilizar o processo de montagem dos treinos.

## US13 — Administrador

> Como administrador, eu quero que o sistema permita cadastrar contas a pagar, para melhorar a organização das atividades financeiras.

## US14 — Administrador

> Como administrador, eu quero que o sistema forneça relatórios personalizáveis usando dados financeiros, para melhorar a tomada de decisões administrativas.

## US15 — Administrador

> Como administrador, eu quero que o sistema permita cadastrar as manutenções realizadas nos equipamentos, para maior controle e segurança.

## US16 — Administrador

> Como administrador, eu quero que o sistema tenha uma interface simples e intuitiva, usando menus semelhantes ao Windows ou Pacote Office, para facilitar o aprendizado do time.

## US17 — Cliente

> Como cliente, eu quero que o sistema me forneça uma planilha de treino simples e intuitiva com exemplos dos exercícios, para melhorar meu aprendizado e autonomia.

## US18 — Cliente

> Como cliente, eu quero que o sistema me envie notificações sobre confirmações de pagamentos, para maior segurança.

## US19 — Cliente

> Como cliente, eu quero que o sistema envie notificações sobre alterações nos horários de funcionamento da academia, para melhorar minha organização.

## US20 — Cliente

> Como cliente, eu quero que o sistema envie notificações sobre promoções dos produtos vendidos na academia, para maior comodidade.

## US21 — Cliente

> Como cliente, eu quero que o sistema me notifique quando minha mensalidade estiver para vencer, para melhorar minha organização.

## US22 — Cliente

> Como cliente, eu quero que o sistema permita feedbacks sobre os treinos, para maior personalização do treino.

## US23 — Cliente

> Como cliente, eu quero que o sistema permita a indicação de músicas para serem tocadas na rádio da academia.

## US24 — Cliente

> Como cliente, eu quero que o sistema permita visualizar com antecedência a lotação da academia, para frequentá-la em um horário com menor ou maior público.
